# Usability Review

Evaluate real task completion, discoverability, keyboard access and recovery in a running interface.

An English-language agent skill from the Cadence project, included in the Ulti Skills collection. The workflow lives in [SKILL.md](SKILL.md); this repository does not include the Cadence application.

## What it produces

- Representative successful and failure-state walkthroughs
- Keyboard, focus, cancellation and draft-preservation checks
- Actionable findings with reproduction and remaining gaps

## Install

For a project-local Codex installation, run this from your project root (Git required):

```sh
git clone https://github.com/hellinckx/ulti-skills.git
```

Copy `ulti-skills/skills/usability-review` into your project at `.agents/skills/usability-review`. Keep the entire skill folder together so relative references and helpers stay available. If that destination already exists, inspect it before updating; do not clone over unrelated work. For a user-wide installation, copy the selected skill folder into your configured Codex skills directory instead. Other agents can load [SKILL.md](SKILL.md) directly or use their own skill installation mechanism.

## Use

Example request:

```text
Use $usability-review.
Walk through creating and editing an appointment with keyboard only. Record actual steps, failures, recovery behavior and corrections without inventing user-test results.
```

## Requirements and integration

Use an agent that can read `SKILL.md` and local reference files. The instructions originated in Cadence; references to its application internals are architectural context, not files included in this repository.

This skill contains instructions; it does not install a service, schedule a task or run code automatically.
