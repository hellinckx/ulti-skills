# Iso World Site

Build websites as a live isometric diorama the camera travels through on scroll — plain HTML, CSS and canvas.

The workflow lives in [SKILL.md](SKILL.md).

## What it produces

- A topic turned into a working miniature: things flow through 4–7 stations and queue at the slow step
- A fixed canvas world behind the page; each chapter rests the camera on one station
- Flat-shaded boxes, ink outlines, hatch stripes and painted mono labels from the subject's vocabulary
- Huge tight headlines, mono utility type and soft glass panels over the hard-edged world
- A palette driven by seven scene tokens, reduced-motion still frames and adaptive quality

## Use

Copy this folder, complete, into your agent's skills directory (for example `.claude/skills/iso-world-site` or `.agents/skills/iso-world-site`), then ask:

```text
Use $iso-world-site.
Build a one-page site for a small bakery in Vienna. Dough batches move from the flour store
through the mixer, proofing and the oven to the counter. Proofing is the slow step.
```
