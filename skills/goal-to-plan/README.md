# Goal to Plan

Turn a short or vague goal into an honest, ordered plan with visible assumptions and measurable acceptance criteria.

The workflow lives in [SKILL.md](SKILL.md).

## What it produces

- An idea check with 2–4 product shapes and sourced research for new products
- Explicit and implicit requirements, non-functional needs and operations
- A dependency-ordered backlog with risky unknowns first and a check per step

## Use

Copy this folder, complete, into your agent's skills directory (for example `.claude/skills/goal-to-plan` or `.agents/skills/goal-to-plan`), then ask:

```text
Use $goal-to-plan.
Turn this goal into a delivery plan: a local inventory app for a small workshop. Derive missing requirements, dependencies and acceptance criteria.
```
